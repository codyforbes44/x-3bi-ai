## App Store Submission Checklist

- [ ] All screenshots at exact required dimensions
- [ ] PNG format, RGB color space
- [ ] 72 DPI minimum resolution
- [ ] File size under 500KB per image (if possible)
- [ ] No placeholder or lorem ipsum text
- [ ] Actual app UI or professional mockups
- [ ] Text overlays clearly readable
- [ ] Consistent branding and style
- [ ] No misleading features shown
- [ ] Compliant with App Store guidelines
