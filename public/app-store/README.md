## 🚀 Screenshot Guidelines

### Best Practices
1. **Show Real Content**: Use actual app features, not mockups
2. **Highlight Key Features**: Each screenshot should showcase a major feature
3. **Use Captions**: Add descriptive text overlays to explain features
4. **Show Different Modes**: Include both light and dark mode examples
5. **Device Frames**: Consider adding device frames for visual appeal
6. **Localization**: Provide screenshots in all supported languages
7. **Consistency**: Maintain consistent branding and style

### Technical Requirements
- PNG or JPEG format
- RGB color space
- 72 DPI minimum
- No transparency
- Portrait orientation preferred
- Proper dimensions for each device size

## 📱 App Preview Videos (Optional but Recommended)

### Specifications
- Length: 15-30 seconds
- Format: M4V, MP4, or MOV
- Codec: H.264 or HEVC
- Resolution: Match screenshot dimensions
